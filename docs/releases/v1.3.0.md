## Quick actions and a full-screen preview

### Quick actions for every kind of clip

Under the preview there's now a row of actions for the selected clip. **⌘O** runs the main "open" action, **⌘K** lists every action, and right-clicking a clip shows them too. "Paste …" actions paste the changed text into the app you were using, without adding it to your history.

| Clip | Actions |
|---|---|
| Link | Open · Paste without tracking (`utm_*`, `fbclid`, `gclid`…) · Paste as Markdown link |
| Text | Open the link inside it · One line · Trimmed · UPPERCASE / lowercase / Title Case |
| Email | New email |
| Phone | Call with FaceTime · Send message · Digits only |
| IP address | Open in browser · Connect with SSH · Address without the `/24` prefix |
| Color | Paste as HEX, RGB, HSL or SwiftUI |
| JSON | Pretty-printed · Minified (both keep your key order) · Code block |
| Command | Without the `$ ` prompt · Code block |
| Code | Code block |
| Path | Show in Finder · Open · Shell-quoted |
| Files | Show in Finder · Open · Paste path |
| Screenshot / image | Paste the text in the image (recognized on your Mac with Apple's Vision framework) |
| UUID / hash | Change case · New UUID |
| Number / card | Plain number · Digits only |

Passwords and secrets have no actions, and card actions never show the number.

### Full-screen preview

Click a screenshot or image, press **Space** (with the search box empty) or **⌘Y** to see the selected clip full screen.

- Pinch or scroll to zoom, drag to pan, and double-click to switch between fit-to-screen and actual pixels.
- **↑ / ↓** move to the next clip while the preview stays open.
- Long text, code and JSON (pretty-printed) are shown at a readable size.
- Space, Esc or a click outside closes it. Images are drawn from memory; nothing decrypted is written to disk.

### Also

- Category filters wrap onto a second row instead of scrolling off the edge.
